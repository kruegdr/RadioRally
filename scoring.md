# Scoring

| ----------- | ----------- | ----------- | ----------- | ----------- | ----------- |
| **Check In** | On Time | Late | Early | +10 min Late | None |
| **Authentication** | OK 1st try | OK 2nd try | OK 3rd try | OK 4th Try | Unable to score points on the stage after 4th failed authentication.
| **Check In Channel** | Primary | Alternate | Contingent | N/A | Unable to score stage points without a check in. |

| **Task Response On Time** | On Time | Late | Early | +10 min Late | None |
| **Task Report Channel** | Primary | Alternate | Contingent | N/A | Unable to score task points without a response.
